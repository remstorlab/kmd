# ДМ-Управление — кликабельный прототип (промт для Figma Make)

Собери веб-приложение «ДМ-УПРАВЛЕНИЕ» — систему учёта драгоценных материалов для склада. Это интерактивный кликабельный прототип: все кнопки, вкладки, строки таблиц и карточки должны реально открывать соответствующие экраны/модалки, с фейковыми (моковыми) данными, без реального бэкенда — состояние можно хранить локально (в памяти приложения).

## 0. Общий стиль и каркас

- Светлая тема для основного контента, тёмная (тёмно-синяя/почти чёрная) шапка+левый сайдбар.
- Шрифт — обычный системный sans-serif (как Inter).
- Акцентный цвет — синий (#2563EB-подобный) для активных пунктов меню и primary-кнопок.
- Верхняя шапка (across всего приложения): слева логотип "Au" в синем квадрате + "ДМ-УПРАВЛЕНИЕ" + разделитель + подпись "Учет драгоценных материалов"; справа — переключатель языка (глобус + "RU"), аватар-инициалы, ФИО "Е. Ковалева" и e-mail "e.kovaleva@monetka-dm.ru".
- Левый сайдбар (тёмный, фиксированный), пункты меню сверху вниз, с иконками:
  1. Склады
  2. Складские операции
  3. Движение материала
  4. Шихтовые карты
  5. Подотчётники
  6. Отчётность
  7. Справочники
  8. Логирование
  9. Панель администрирования
  Активный пункт подсвечен синим.
- На каждой странице раздела — breadcrumb-строка (напр. "Склады / Остатки на складе ГП") и справа "Обновлено: <дата, время>".
- Общий паттерн таблицы позиций с CRUD (используется много раз — «Позиции прихода», «Позиции приёма», «Выдача», «Возврат», «Шихтовые материалы»): заголовок раздела + кнопка(и) действия ("+ Добавить позицию" / "+ Добавить со склада" / "+ Добавить доп. материал" / "+ Выдать по ШК") + кнопка "Экспорт в Excel" справа от неё; сама таблица со столбцами под конкретный контекст; у каждой строки три иконки в конце: "глаз" (просмотр — открывает форму добавления в режиме read-only), "карандаш" (редактирование — та же форма, предзаполненная, кнопка "Сохранить"), "крестик в круге" (удаление — подтверждение и удаление строки из таблицы).
- Статус-бейджи (цветные пилюли), общая логика цвета: зелёный — позитивный/финальный статус (Активен, На складе, Выполнено, Соответствует, Без изменений), жёлтый — промежуточный/предупреждение (Резерв, В работе, Частично, Превышение), синий — нейтральный тип/этап (В обработке, В подотчёте, Изменена, Новая), красный — негатив (Заблокирован, Утрачена), серый — нейтральный финальный (Закрыт).
- Модалки — по центру экрана, с полупрозрачным затемнением фона, крестик закрытия справа в заголовке, футер с кнопками справа (вторичные — белые с рамкой, primary — синие, опасное действие "Списать разницу" — красная рамка/текст).

```

Складские операции (хаб)
 ├─ Приход на склад → список документов
 │    ├─ модалка выбора "Принять на склад..." → "Приходный ордер" | "Накладная на приём"
 │    ├─ модалка "Приходный ордер" → "Добавить позицию ДМ" (форма)
 │    ├─ модалка "Накладная на приём ГП" → "Добавить позицию ГП" (форма)

      └─ Итого → кнопка "Списать разницу" → модалка "Списание разницы"

Шихтовые карты → список карт
 └─ модалка "Конструктор шихтовой карты"

 └─ Карточка подотчётного лица (страница, не модалка)

Справочники → 8 карточек словарей → страница словаря (таблица Код/Значение/Статус)

 ├─ модалка "Новый пользователь"
 └─ "Управление ролями" → страница "Роли и разрешения"

```

## 2. Склады

### 2.1 Склады (хаб)
Заголовок "Склады", подпись "Выберите раздел". Две крупные карточки-переключателя (с тумблером сверху, по умолчанию оба "включены"):
- «Остатки на складе ГП» / «Готовая продукция» → переход на 2.2
- «Остатки на складе ДМ» / «Драгоценные материалы» → переход на 2.3

### 2.2 Остатки на складе ГП
Заголовок + подпись «Актуальные позиции готовой продукции». Кнопки справа: «Принять на склад» (primary) → модалка «Накладная на приём ГП» (3.2 в пустом виде); «Выдать со склада» → модалка «Накладная на отгрузку ГП» (3.5, пустая); «Экспорт в Excel».
Фильтры: Склад / Наименование (поиск) / Код материала / Статус / Сбросить фильтры.
Таблица (чекбоксы слева): Наименование, Номенкл.№, Количество, Класс, Код материала, Статус (бейдж: На складе/Резерв/В обработке), иконка "глаз" справа → карточка просмотра позиции (read-only).
Пагинация "Показано 1–8 из 34 позиций", постранично 1/2/3.

### 2.3 Остатки на складе ДМ (Остатки материалов)
Заголовок «Остатки материалов на складе», подпись «Актуальные позиции по всем складам, сейфам и полкам». Кнопки: «Принять на склад» → модалка выбора 3.1; «Выдать со склада» → модалка «Накладная на отгрузку» (аналог 3.5, но для ДМ); «Объединить номенклатуры» (активна при выборе ≥2 строк чекбоксами) → модалка «Объединение номенклатур»; «Экспорт в Excel».
Фильтры: Склад / Наименование / Класс материала / Статус / Сбросить фильтры.
Таблица: чекбокс, Наименование, Номенкл.№, Класс, Проба, Лигат. вес г, Чистый вес г, Место хранения, Статус (На складе/Зарезервировано/В подотчёте), иконка "глаз".

### 2.4 Модалка «Объединение номенклатур»
Открывается при выборе 2+ строк в 2.3 и клике «Объединить номенклатуры». Список выбранных позиций (наименование, номенкл.№, вес), ниже блок «ИТОГОВАЯ ПОЗИЦИЯ»: Класс, Средняя проба, Лигатурный вес, Чистый вес (авторасчёт — сумма весов/средневзвешенная проба). Футер: Отмена / «Подтвердить объединение» → заменяет выбранные строки одной новой строкой в таблице 2.3, закрывает модалку.

## 3. Складские операции

### 3.0 Складские операции (хаб)
Три карточки: «Приход на склад» / «Приходные ордера и накладные» → 3.1(список); «Выдача ГП» / «Документы отгрузки ГП» → 3.4(список); «Движение материала (операции)» / «Журнал операций» → раздел 4.1.

### 3.1 Складские операции / Приём (список)
Заголовок + подпись «Документы приёма и выдачи материала». Кнопки: «Принять на склад» (primary) → модалка выбора; «Выдать со склада» → накладная на отгрузку; «Печать ярлыков ДМ» → модалка печати ярлыков (без привязки к конкретному документу — общий выбор).
Фильтры: Дата С-По (календарь) / Тип документа (поиск) / Номер (select "Все") / Статус / Сбросить фильтры.
Таблица: Дата, Тип документа (Приходный ордер/Накладная), Номер, Статус (Выполнено зелёный / В работе синий / Закрыт серый), Отправитель, Получатель, иконки "глаз" (просмотр документа, read-only) и "принтер" (печать документа).
Клик по строке типа «Приходный ордер» (глаз) → модалка 3.3 в режиме просмотра; по строке «Накладная» → модалка 3.4б в режиме просмотра.

### 3.2 Модалка выбора «Принять на склад...»
Заголовок + подпись «Выберите способ оформления приёма на склад». Две большие плитки: «По приходному ордеру» (primary, синяя) → открывает 3.3; «По накладной» → открывает модалку «Накладная на приём ГП» (3.4б, для ГП-контекста) либо аналогичную накладную для ДМ (та же форма/структура, другой список полей не меняется).

### 3.3 Модалка «Приходный ордер»
Поля (2 колонки): Тип документа, Номер, Дата / Отправитель, Получатель / № счёт-фактуры, Дата счёт-фактуры, Номер договора, Дата договора / тумблер «Собственность заказчика: Да», Номер паспорта / Номер платёжного документа, Дата платёжного документа / Лигатурный вес по документу, Масса по документу / Принято лигатурный вес, Принято чистый вес / Цена за единицу тг, Сумма в тенге / Позиция годового плана (на всю ширину).
Блок «Документы»: чип с иконкой скрепки "Приходный ордер ПО-0342.pdf" + кнопка скачивания.
Блок «ПОЗИЦИИ ПРИХОДА»: кнопки «+ Добавить позицию» → модалка 3.3а; «Экспорт в Excel». Таблица: Номенкл.№, Наименование, Класс, Код м-ла, Проба, Лигат., Чистый, Размещение, иконки глаз/карандаш/крестик.
Футер: «Печать Ярлыков ДМ» → модалка 3.6 (предзаполнена позициями этого документа); «Сохранить»; «Сохранить и печать» — обе сохраняют документ, закрывают модалку, добавляют/обновляют строку в списке 3.1 со статусом «Выполнено».

### 3.3а Модалка «Добавить позицию ДМ»
Поля: Номенклатурный номер (select), Класс (select, по умолчанию «Слиток»), Код материала (select) — одна строка из трёх; Наименование (текст, на всю ширину); Масса лигатурная г, Масса чистая г, Проба — одна строка; блок «Содержание в чистоте, г»: Ag, Cu, Fe, Sb / Bi, Pb, P (поля ввода, по умолчанию «–»); блок «Размещение»: Сейф (select), Полка (select). Футер: Отмена / «Добавить» → добавляет строку в таблицу «Позиции прихода» модалки 3.3 и закрывает эту форму. В режиме редактирования кнопка меняется на «Сохранить», в режиме просмотра — все поля disabled и одна кнопка «Закрыть».

### 3.4 Складские операции / Выдача (список)
Заголовок + подпись «Документы приёма и выдачи материала». Кнопка «Выдать со склада» → модалка 3.5.
Те же фильтры, что в 3.1. Таблица: Дата, Тип документа (Накладная на отгрузку ГП / Накладная на отгрузку), Номер, Статус (В работе/Закрыт), Отправитель, Получатель, иконки глаз/принтер. Клик глаз → модалка 3.5/3.4б в режиме просмотра.

### 3.4б Модалка «Накладная на приём ГП»
Поля: Тип документа, Номер, Дата / Заказчик, Склад-отправитель / Склад-получатель, Сотрудник склада-получателя. Блок «Документы» (чип+скачать). Блок «ПОЗИЦИИ ПРИЁМА»: «+ Добавить позицию» → модалка 3.4в; «Экспорт в Excel». Таблица: Номенкл.№, Наименование, Кол-во, Класс, Код материала, Размещение, иконки глаз/карандаш/крестик. Футер: «Сохранить и печать» / Отмена / «Сохранить» → сохраняет и возвращает в список (3.1 или 2.2 в зависимости от того, откуда открыли).

### 3.4в Модалка «Добавить позицию ГП»
Поля: Номенклатурный номер (select) / Класс (select, по умолчанию «Монета») / Код материала (select) — одна строка; Наименование (текст); Количество, Ед. изм. (select) — одна строка; блок «Размещение»: Сейф, Полка. Футер: Отмена / «Добавить» → добавляет строку в таблицу 3.4б.

### 3.5 Модалка «Накладная на отгрузку ГП» (используется и для отгрузки ДМ)
Поля: Тип документа (select, напр. «Накладная на приём ГП»/своя), Номер, Дата / Получатель, Счёт-фактура. Блок «Документы». Заголовок «ВЫБЕРИТЕ МАТЕРИАЛ(Ы) ДЛЯ ВЫДАЧИ СО СКЛАДА»: «+ Добавить позицию» → модалка 3.5а; «Экспорт в Excel». Таблица выбранных позиций: Номенкл.№, Наименование, Кол-во, Класс, Код материала, Размещение, иконки глаз/карандаш/крестик. Футер: Отмена / «Оформить выдачу» → сохраняет, закрывает, добавляет строку «В работе» в список 3.4/остатки уменьшаются.

### 3.5а Модалка «Добавить материал со склада»
Фильтры сверху: Наименование (поиск), Склад (select), Класс ГП (select). Таблица с чекбоксами: Наименование, Номенкл.№, Класс, Доступно (число), Количество (редактируемое поле, активно только при отмеченном чекбоксе), Место хранения. Низ: счётчик «Выбрано: N позиции», Отмена / «Добавить выбранные» → переносит отмеченные строки (с указанным количеством) в таблицу модалки 3.5.

### 3.6 Модалка «Печать ярлыков ДМ»
Заголовок + «Выбрать все» / «Снять все» ссылки, справа счётчик «Выбрано: N из M». Таблица с чекбоксами: Позиция, Масса г, Класс, Ag, Cu, Fe (и т.д. по составу). Футер: Отмена / «Печать выбранных» → имитация печати (тост/уведомление), закрывает модалку.

## 4. Движение материала

### 4.1 Движение материала / Реестр операций
Заголовок + подпись «Выдача и возврат материалов подотчётным лицам». Кнопки: «Оформить возврат» → модалка 4.2 сразу с открытой вкладкой «Возврат» для выбора уже выданной операции; «Новая операция» → модалка 4.2 в пустом состоянии.
Фильтры: Дата С-По / Тип операции (поиск) / Документ (поиск) / Вид (select) / Подотчётник (select) / Статус / Сбросить фильтры.
Таблица: Дата, Тип (Выдача/Возврат/Выдача-Возврат — цветной текст), Вид операции (Отбор пробы/ЛКИ/Плавка/Гальванопокрытие/Производство — ссылка), Материалы/Позиции (число + иконка глаз — открывает 4.2 в read-only на вкладке, где эти позиции), Документ, Подотчётник, Статус (Выдано зелёный/Закрыто серый), иконки глаз/карандаш/крестик справа → открывают/редактируют/удаляют соответствующую операцию (модалка 4.2).

### 4.2 Модалка «Движение материала» (параметризуемая по «Виду»)
**Шапка**: заголовок "Движение материала" (или "Движение материала — <Вид>", когда Вид выбран), крестик закрытия. Справа от заголовка — три статус-бейджа: «Статус выдачи» (Выдано/Не выдано), «Статус возврата» (Не начат/Возврат: частично/Возврат: полностью), «Статус закрытия» (Не закрыто/Закрыто: списано/Закрыто). Показываются только когда операция уже сохранена (не в пустой новой форме).

**Блок полей вне таблиц** (общий для всех вкладок, не дублируется):
- Если операция новая: два select — «Тип операции» (Выдача / Выдача-Возврат / Возврат) и «Вид» (Отбор пробы / ЛКИ / Плавка / Гальванопокрытие / Производство) — выбор Вида делает видимым остальной блок и вкладки.
- После выбора Вида — единые поля в 2 колонки: Тип операции, Вид (заполненные, недоступные для смены) / Тип документа, Номер документа / Дата операции, Заказчик / Подотчётное лицо (на всю ширину) / Выдал, Получил.
- Доп. поля по видам: «Плавка» добавляет строку Материал (select, напр. «Золото (Au)»), Номер плавки; «Производство ГП» добавляет Разрешил (select) поверх строки Выдал/Получил; «Гальванопокрытие» добавляет одиночное поле «Вес переданный, г».

**Вкладки** (в таком порядке): Выдача | Возврат | Итого.

- **Вкладка «Выдача»**: кнопка(и) добавления — «+ Добавить позицию» (Отбор пробы/ЛКИ/Гальванопокрытие/Производство) или «+ Выдать по ШК» + «+ Добавить» (Плавка, «Выдать по ШК» открывает выбор готовой шихтовой карты из раздела 5 и подставляет её состав) + «Экспорт в Excel». Таблица столбцы: №, Наименование, Номенк.№, Класс, Проба, Вес г, Ag, Cu (Плавка/Гальванопокрытие/Производство добавляют Fe, Sb, Bi, Pb, P; Производство добавляет столбец Количество), Размещение, иконки глаз/скрепка(редактировать)/крестик. Ниже иногда блок «Документы» (чип "Приказ-001234.pdf" + скачать) — для Плавки и Производства.
- **Вкладка «Возврат»**: аналогичная структура, своя кнопка «+ Добавить»/«+ Добавить позицию», своя таблица (в возврате могут появляться совсем другие номенклатуры — например при Плавке: «Подкат 30х20», «Подкат 50х30», «Королёк №1», «Шлак золотосодержащий»; при Производстве: «Монета «Барс» 1 oz», «НП Заготовка кольцо Au», «Козел остаток подката», «Перфолента»), свой блок «Документы» (чип "МСЛ-001234.pdf").
- **Вкладка «Итого»**: сверху компактная плашка дельты веса: иконка (⚠ жёлтая при превышении / ✓ зелёная в норме) + текст «Дельта: <знак><значение> г (допуск: ±<значение> г) <В норме!/Превышение!>» + кнопка «Списать разницу» (красная рамка) справа от плашки — открывает модалку 4.3.
  Ниже — один или несколько блоков «Операция N — <краткое название, напр. "Плавка золотых слитков">», каждый содержит:
  - подзаголовок «ВЫДАЧА» и список позиций выдачи, участвующих в этой операции (наименование+номенк.№, вес/кол-во, статус-бейдж справа: «Без изменений» / «Изменен» / «Преобразован»);
  - разделитель «↓ связь ↓»;
  - подзаголовок «ВОЗВРАТ» и список позиций возврата, связанных с этой операцией (наименование, вес/кол-во, статус-бейдж: «Без изменений» / «Изменен» / «Новая» / «Утрачена»).
  Важно: связь МНОГИЕ-КО-МНОГИМ — несколько позиций выдачи могут превращаться в несколько позиций возврата в рамках одной "Операции N" (пример: 2 позиции выдачи «Преобразован» → 4 позиции возврата: 2×«Без изменений», 1×«Новая», 1×«Утрачена»; другой пример: 3 позиции выдачи (2×«Преобразован», 1×«Изменено») → 4 позиции возврата (3×«Новая», 1×«Изменено»)). Если операций/связок несколько — блоки «Операция 1», «Операция 2» идут друг за другом.

**Футер** (общий для всех вкладок): Отмена / «Сохранить и печать» / «Сохранить» → сохраняет документ целиком (все три вкладки), закрывает модалку, обновляет/добавляет строку в 4.1 со статусами сверху.

### 4.3 Модалка «Списание разницы»
Открывается из вкладки «Итого» кнопкой «Списать разницу». Жёлтый предупреждающий баннер «⚠ Превышение допустимой дельты: <значение> г». Поле «ПРИЧИНА СПИСАНИЯ» (textarea, плейсхолдер «Укажите причину списания разницы весов…»). Блок «АКТ СПИСАНИЯ (обязательно)» — dropzone «📎 Прикрепите файл акта списания, PDF, DOCX — до 10 МБ»; после выбора файла показывается чип с его именем (напр. "Акт списания ДМ-000123.pdf"). Кнопка «Списать разницу» (красная, primary) неактивна, пока файл акта не прикреплён; по клику — сохраняет списание, закрывает модалку, обновляет статус-бейдж «Статус закрытия» на «Закрыто: списано». Кнопка Отмена — закрывает без сохранения.

## 5. Шихтовые карты

### 5.1 Список шихтовых карт
Заголовок + подпись «Расчёт состава шихты для плавки слитков». Кнопка «Новая шихтовая карта» → модалка 5.2 пустая. Таблица: Дата, Наименование, № плавки, Статус (Подготовлена к плавке жёлтый / Выполнено зелёный / В работе синий), иконка «глаз» → модалка 5.2 в режиме просмотра/редактирования.

### 5.2 Модалка «Конструктор шихтовой карты»
Поля: Наименование, Номер плавки / Номер оборота, Назначение слитков / Основание (текст + кнопка скачивания рядом).
Блок «ШИХТОВЫЕ МАТЕРИАЛЫ»: кнопки «+ Добавить со склада» → модалка 5.3; «+ Добавить доп. материал» → модалка 5.4. Таблица: Материал, Класс, Fe г, Sb г, Bi г, Pb г, P г, Вес г, Доля %, иконки глаз/карандаш/крестик.
Кнопка «🧮 Рассчитать» → показывает блок «РЕЗУЛЬТАТ: СООТВЕТСТВИЕ ГОСТ»: строки Золото(Au)/Серебро(Ag)/Медь(Cu) — процент, «норма X-Y», бейдж «соответствует» (зелёный) или «не соответствует» (красный), пересчитывается при каждом добавлении/удалении материала.
Футер: Отмена / «Сохранить карту» → сохраняет, закрывает, добавляет/обновляет строку в 5.1.

### 5.3 Модалка «Добавить материал со склада» (для шихты)
Фильтры: Наименование (поиск), Склад (select), Класс материала (select). Таблица с чекбоксами: Наименование, Номенкл.№, Класс, Проба, Лигат. вес г, Чистый вес г, Место хранения. Низ: «Выбрано: N позиции», Отмена / «Добавить выбранные» → добавляет строки в таблицу «Шихтовые материалы» модалки 5.2.

### 5.4 Модалка «Добавить дополнительный материал»
Поля: Наименование материала (текст) / Код материала, Класс (select) / Проба, Ед. измерения / Вес г. Блок «СОДЕРЖАНИЕ (СОСТАВ)» — таблица Элемент/Содержание %/Масса г со строками Au, Ag, Cu, Fe, Прочие (расчёт массы = вес × %/100, автообновление при вводе). Футер: Отмена / «Добавить» → добавляет строку в таблицу модалки 5.2.

## 11. Сквозные правила интерактивности
- Любая иконка «глаз» в таблице открывает соответствующую форму/модалку в режиме просмотра (поля недоступны для редактирования, одна кнопка «Закрыть»).
- Любая иконка «карандаш»/скрепка в таблице — та же форма, предзаполненная данными строки, доступна для правки, кнопка сохранения подписана «Сохранить».
- Любая иконка «крестик в круге» в таблице — показывает confirm-диалог «Удалить позицию?» (Отмена/Удалить), при подтверждении убирает строку.
- Крестик/✕ в заголовке любой модалки и кнопка «Отмена» в футере — закрывают модалку без сохранения изменений.
- Все кнопки «Экспорт в Excel» / «Экспорт» / «Печать…» / «Скачать» — имитация действия (короткий тост-уведомление «Готово», без реального файла).
- Данные между экранами должны быть согласованы: если в 3.3 добавили позицию — она должна появляться и в связанном списке остатков 2.3; если в 4.2 сохранили операцию со статусом «Выдано» — соответствующая строка появляется в реестре 4.1 и в балансе подотчётного лица 6.2.
